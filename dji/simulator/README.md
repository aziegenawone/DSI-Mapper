# DJI Flight Simulator Setup

## Prerequisites

1. **DJI Matrice 30T** connected via USB to your PC
2. **DJI Assistant 2 Enterprise** installed
3. **DJI Pilot 2** on the RC Plus controller

## Steps

1. Connect M30T to PC via USB
2. Open DJI Assistant 2 Enterprise
3. Enable Simulator mode in the assistant
4. The simulator creates a virtual flight environment
5. On the RC Plus controller, open DJI Pilot 2
6. Import a KMZ file generated by DSI Mapper
7. Start the mission — the drone will "fly" virtually in the simulator
8. Verify: flight route, camera triggers, area coverage

## Testing Workflow

```
DSI Mapper (Flight Planner)
    → Export KMZ
    → Load on DJI Pilot 2 (RC Plus)
    → DJI Simulator (M30T connected to PC)
    → Virtual flight execution
    → Verify waypoints, camera actions, coverage
```

## Notes

- The simulator requires a physical M30T — there is no pure-software alternative
- Flight telemetry is logged during simulation
- Camera trigger events are simulated but no actual images are captured
- Use this to validate flight plans before real field missions
